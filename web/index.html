Orkestro Takeoff

Orkestro Takeoff is a construction and flooring takeoff canvas built on OpenTakeoff, the open-source (AGPL-3.0) takeoff engine. Measure plans in your browser, set scale per sheet, and get SF, SY, LF and EA quantities, a materials buy list and marked-up plan set exports. Opening a plan uploads nothing.

This page is the takeoff app itself, and it needs JavaScript.
